# Currency Converter

Simple React + TypeScript app to convert amounts between currencies with a clean UI. It uses Redux Toolkit for state, Ant Design/Bootstrap for styling, and provides instant calculations as you type.

## Available Scripts

In the project directory, you can run:

### `npm start`

Runs the app in development mode. Open [http://localhost:3000](http://localhost:3000).

### `npm run build`

Builds the app for production to the `build` folder.

## Tech Stack

- React 18, TypeScript
- Redux Toolkit, React Redux
- Ant Design, Bootstrap, SCSS modules
